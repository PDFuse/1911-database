# Individual Pistol Pages

Place individual pistol record pages in this folder.

Use simple serial-number filenames whenever possible.

Examples:

- `2335201.html`
- `856405.html`
- `S800001.html`

Each page should include:

- Serial number
- Manufacturer
- Year/range result
- Inspector marks
- Slide/frame notes
- Finish notes
- Arsenal rebuild notes
- Photo gallery
- Verification notes
